# Roadmap

## Phase 0 — Foundation

- Tooling, CI, Docker PostgreSQL, Drizzle migrations, seed data
- Internationalization, design tokens, shared UI primitives
- Architecture, data model, operating conventions

## Phase 1 — Homepage

- Responsive, database-backed homepage and search placeholder
- Metadata, sitemap, robots, structured-data placeholders
- Unit, component, and Playwright smoke coverage

## Later phases

1. Search results and listing detail SEO
2. Authentication, profiles, seller verification
3. Listing creation and media storage
4. Conversations, favorites, reports, moderation
5. Grooming and boarding booking flows
6. Reviews, notifications, admin tooling, payments

Each later phase requires a threat/privacy review and country-specific legal validation before production release.
